# 보정사진 한 장씩 넘기기

## 승인된 방향

사용자가 선택한 방식은 사진을 한 장씩 크게 보고 좌우 스와이프 또는 화살표로 보정 버전을 순서대로 넘기는 방식이다. 버전명과 `1/4` 같은 현재 위치를 항상 표시한다. 두 사진을 겹치는 경계선 슬라이더는 만들지 않는다.

## 화면과 조작

- 기존 2·3·4장 비교 묶음 모두 같은 한 장 보기로 통일한다. 목록의 각 촬영 컷과 확대창에서 한 번에 한 버전만 보인다.
- 첫 진입은 기존 순서의 첫 버전이다. 좌우 버튼 또는 가로 스와이프로 다음/이전 버전을 선택하며, 마지막 다음은 첫 번째로 돌아간다. 세로 스크롤은 그대로 가능하다.
- 버전 이름과 `버전 2/4`를 사진 바깥에 표시한다. 촬영 컷 번호는 `촬영 컷 1/9`처럼 별도로 표시하여 혼동을 막는다.
- 사진을 누르면 현재 보고 있던 버전으로 확대창을 연다. 확대창 좌우 방향키는 버전을 넘긴다. 다른 촬영 컷으로 이동하는 버튼에는 `이전 촬영 컷`·`다음 촬영 컷`을 명시한다.
- 확대창에서 선택한 버전은 해당 목록 카드에도 반영하여 닫은 뒤에도 같은 버전이 보이게 한다. 탭을 바꾸면 해당 탭은 첫 버전부터 시작한다.
- 확대율 100%에서 가로 드래그는 버전 넘기기이고, 확대 중 드래그는 사진 내부 이동이다. 확대 중에도 버전 버튼과 방향키는 작동하며 확대율과 이동 위치를 유지한다. 다른 촬영 컷으로 이동하면 첫 버전·100%로 초기화한다.
- 스와이프 직후 클릭으로 확대창이 열리는 오작동을 막고, 세로 이동이나 취소된 제스처는 버전을 바꾸지 않는다. 멀티터치를 버전 전환으로 오인하지 않는다.
- 사진은 같은 크기의 프레임 안에서 비율과 전체 구도를 유지한다. 휴대폰 세로 화면에서도 사진·버전명·버튼이 넘치지 않게 배치한다. 자동 재생은 없다.

## 구현 범위

기존 정적 HTML/CSS/JavaScript 구조와 공통 패널 정규화 함수를 유지한다. 렌더링을 현재 선택한 버전 하나와 이전/다음 조작부로 변경하고 촬영 컷 인덱스와 버전 인덱스를 분리한다. 확대창의 기존 확대·이동 상태를 재사용한다.

수정 대상은 `shared-photo-comparison/index.html`, 로컬 `글렌셀렉/보정사진_비교.html`, 관련 `tests/*.test.mjs`다. 두 HTML의 이미지 경로, 로컬 원본 열기, 네트워크/OneDrive 오류 안내 차이는 보존한다. 접근성 이름, 키보드 포커스 복귀, 닫기/Escape, 이미지 오류 안내와 지연 로딩을 유지한다. 숨겨진 버전이 키보드 탐색이나 스크린리더에 중복 노출되지 않게 한다.

사진 파일·보정 내용·버전 순서는 바꾸지 않는다. 21개 비교 묶음, 고유 사진 53장, 54개 패널 참조를 유지한다. 외부 라이브러리나 새 서버는 추가하지 않는다.

## 검증 및 배포

기존 데이터·파일 검증을 유지하고 한 장 표시, 버전 순환, 선택한 버전 확대, 확대 상태 유지, 컷 이동 초기화, 가로/세로 제스처 구분에 대한 회귀 테스트를 추가한다. PC와 휴대폰 크기에서 실제 브라우저로 확인한다. 성공 후 기존 GitHub Pages에 배포하고 공개 페이지에서 4개 버전의 표시와 전환을 확인한다. 로컬 고화질 사진은 변경하지 않는다.
